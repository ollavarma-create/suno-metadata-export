# Suno Music Collection

Music created with a paid [Suno.com](https://suno.com) license.
Lyrics and song structures are my own work; instrumentation and production by Suno.com.

## About This Repository

This repository contains metadata and lyrics for 539 publicly released tracks I created
between December 2024 and December 2025 using [Suno.com]. The `song-meta/` directory contains a browsable
[catalog](song-meta/catalog.md) and a [JSON file](song-meta/catalog.json) with full metadata and lyrics for all tracks.
(Note: original songs are removed from Suno.com)

The `articles/` directory contains three articles I originally published on LinkedIn,
covering the creative process, therapeutic potential of AI music, and lessons learned
from trying to monetize AI-generated content.

## How the Music Is Made

My creative process begins with a human idea, which I refine using locally hosted
language models in [LM Studio](https://lmstudio.ai/). I use Retrieval-Augmented
Generation (RAG) to enrich the lyrics with material from my own essays, theses, and
reflections drawn from my background in psychology, biology, pedagogy, social sciences,
and computer science.

A typical workflow looks like this:

1. **Ideation** — I start from a theme or emotional concept.
2. **Prompting the LLM** — I craft a detailed prompt including mood, structure
   (verse/chorus/bridge), and stylistic elements like onomatopoeia or metaphors.
3. **Refining** — I iterate on the generated lyrics, editing for emotional depth
   and narrative coherence.
4. **Music generation** — I test several instrumentals on Suno to find the best
   emotional match for the lyrics.

All processing runs locally for privacy — I can safely incorporate personal experiences
and sensitive themes without sharing them with cloud services.

## The Export

At the time of export (April 24, 2026), my Suno library contained **2,394 total
generations** — Suno creates two variations per prompt, and many tracks went through
multiple iterations. Of these, about **539 are publicly released** tracks that I consider
finished work. This repository includes only these public tracks.

The export was performed using a browser console script (`tools/suno-export.js`) that
authenticates via Suno's Clerk session and paginates through the Studio API to collect
all song metadata, including lyrics. The script ran 120 API calls in about 72 seconds.

## Articles

These articles were originally published on LinkedIn in 2025:

1. **[Tools, Techniques & Ownership](articles/part1-tools-techniques-ownership.md)** —
   Overview of AI music platforms (Suno, Udio, Riffusion), copyright considerations,
   practical tips on LLM prompting for lyrics, and the steganography tool for

2. **[Melodies of the Mind](articles/part2-melodies-of-the-mind.md)** —
